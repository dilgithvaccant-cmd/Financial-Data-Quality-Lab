# Repository instructions

- Work on purpose-specific branches and submit draft pull requests.
- Do not merge, delete branches, change settings, or publish releases without explicit approval.
- Use synthetic data only; never commit real employer, customer, or supplier data.
- For Python changes, run `python -m pytest -q`.
- Preserve deterministic validation behavior and document assumptions and limitations.
- Review changes for secrets and unintended files before proposing a merge.
